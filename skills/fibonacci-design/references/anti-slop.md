# Anti-Slop Catalog

Ask two questions of every artifact.

1. Does it look like absolute AI slop?
2. Does it contain AI patterns?

If yes to either, do not polish. Identify the pattern, think of a structural fix, apply it, then ask again.

Slop is not "simple." Slop is generic structure wearing trendy skin. Fibonacci work can be sparse. It cannot be default.

## Immediate fails

Any two of these on one page is an automatic rebuild.

- Purple-to-blue gradient on a dark field
- Frosted-glass cards over a blurred aurora
- Three equal rounded feature cards with a pastel icon tile
- Hero headline + subtitle + two pills + product screenshot in a glowing browser frame
- Bento grid of mixed tiles with no hierarchy
- Floating 3D torus / spline / blob / grain overlay
- Inter or Roboto at 16 / 24 / 32 with 12px radii and 24px padding everywhere
- Emoji used as navigation icons
- A decorative golden spiral, φ watermark, or "sacred geometry" background
- Testimonial row of three identical avatar-quote cards
- Logo cloud as a substitute for proof
- Big rounded search bar under a centered slogan and nothing else considered

## Pattern → structural fix

### The triad of sameness

Pattern — three equal columns, three equal cards, three equal steps.

Fix — break equality. One mass at 61.8%, a supporting list at 38.2%. Or one editorial block and a quiet numbered stack. If there really are three things, make the first one larger and the other two share the minor.

### The SaaS landing stencil

Pattern — nav, hero, logos, features-in-3, how-it-works-in-3, quotes, pricing-in-3, footer.

Fix — keep only the story the user asked for. One claim, one demonstration, one act. Move the rest off the first view or delete it.

### Chrome without a spine

Pattern — every block is a rounded rectangle with a soft shadow, stacked in a centered max-width 72rem column.

Fix — introduce a spine. Large unboxed field. One lifted plane at most. Align to a left or golden column, not a floating island of cards.

### Icon tiles

Pattern — 8×8 rounded square in a tinted fill, generic stroke icon, title, two lines of copy. Repeated.

Fix — drop the tiles. Set the title as type. If an icon is needed, place it as a mark on the baseline, same color as structure, no pedestal.

### Gradient as personality

Pattern — color does the work that structure failed to do.

Fix — flatten the field. Put the hue in one accent object (a rule, a numeral, a link, a single plane). Neutrals do the rest.

### Fake depth

Pattern — layered blurs, inner glows, inner highlights, noisy grain, glass.

Fix — one real plane change. A hairline, a 1-step tone shift, or a single soft shadow with low opacity and large radius. Never all four.

### Centered everything

Pattern — every heading, every button row, every paragraph centered, on every breakpoint.

Fix — center only a ceremonial opening or a short closing mark. Reading text left-aligns. Controls follow the text spine.

### Type costume

Pattern — a fashionable display face for one word, then a mismatched UI sans, then a mono for no reason.

Fix — one family, or a display + text pair that shares skeleton. Mono only for actual code or data.

### Component parade

Pattern — the page exists to show buttons, chips, tabs, and cards in every state.

Fix — design the user's task. Components appear where the task needs them, in the scale of the page, not as a kit.

### Empty calm

Pattern — huge whitespace, a single line of timid copy, no hierarchy. Looks "minimal" and says nothing.

Fix — calm is composed, not vacant. Increase type one Fibonacci step, tighten the measure, add one true secondary mass.

### Sacred-geometry cosplay

Pattern — visible spirals, overlapping circles, annotated φ, "Fibonacci" as brand decoration.

Fix — delete the diagram. Keep the proportions. The page should not explain itself.

### Motion slop

Pattern — hero numbers count up, cards lift and tilt, orbs drift, scroll-jacked parallax.

Fix — freeze. Animate only state change. If a number must change, let it change once, in 340ms, without bouncing the layout.

## How to look at it cold

After you think you are done, imagine the page at 200px tall in a grid of other generated pages. If you could not pick yours out, it is slop.

Then imagine it printed in one ink on cheap paper. If the structure still holds — spine, measure, grouping — the design is real. If only the gradient held it together, rebuild.

## Rebuild protocol

1. Name the two slop patterns you see.
2. Delete ornament first (gradients, glass, tiles, spirals, orbs).
3. Re-establish the golden split and the gap scale.
4. Re-set type to five steps or fewer.
5. Put the dominant idea in the major column.
6. Run layout physics again.
7. Ask the two questions again. Do not ship on a yes.
