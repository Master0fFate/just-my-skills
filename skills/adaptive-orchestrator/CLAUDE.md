# Adaptive orchestration policy

Consider `adaptive-orchestrator` when bounded independent outcomes, specialist capability, or independent checks can improve the result enough to justify delegation cost. Keep simple or tightly coupled work in the parent. Reuse the existing task contract; do not add another planning ceremony.

The parent keeps scope, authorization, allocation, integration, verification, and the final response. Follow host capacity and permissions, assign one writer per resource, and treat worker output as evidence to verify. Use only actual tools and model controls. If delegation is unavailable or forbidden, work serially without claiming workers were used.

Follow the installed `adaptive-orchestrator/SKILL.md`. In a compatible `.claude` layout, it is at `.claude/skills/adaptive-orchestrator/SKILL.md`. This wrapper neither installs tools nor grants permissions.
