# Adaptive orchestration policy

For every task, silently assess whether the `adaptive-orchestrator` skill applies. Apply it proactively to complex, multi-step, research-heavy, implementation-heavy, high-volume, cross-domain, or high-impact work; do not wait for the user to request subagents, reviewers, verifiers, or auditors. Keep simple work single-agent. The parent agent must retain planning, authority, integration, verification, and the final response.

Follow `.claude/skills/adaptive-orchestrator/SKILL.md` when that path exists. If the skill is installed at another supported location, follow the installed `adaptive-orchestrator` skill instead.
